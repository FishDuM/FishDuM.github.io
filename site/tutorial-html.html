HTML 负责网页的内容和结构

如果把一个网页看成一栋房子，那么 HTML 更像房子的骨架。它不负责颜色、动画和复杂交互，而是负责告诉浏览器：这里有标题，这里有正文，这里有图片，这里有导航，这里有表单。

先理解 HTML 在解决什么问题

很多初学者会把 HTML 理解成“背标签”，但真正重要的是先理解它在做什么。HTML 的任务不是让页面变好看，而是把页面里的内容组织清楚，让浏览器知道每一块内容分别是什么。

网页里到底有什么

当你准备写一个页面时，第一步不是急着想颜色和布局，而是先把内容想清楚。比如，一个页面可能会有站点标题、一段介绍、一张图片、一个项目列表、一个联系方式表单。HTML 要做的，就是把这些内容用合适的标签表达出来。

例如，标题通常用 `h1` 到 `h6`，段落通常用 `p`，链接通常用 `a`，图片通常用 `img`。这些标签并不是为了凑语法，而是为了让页面结构更清楚。

最常见的基础标签

实际开发里最常用的 HTML 标签没有那么多。你先把高频的一批理解清楚，就已经足够写出大部分简单页面。

  • `h1` 到 `h6`：表示不同层级的标题。
  • `p`：表示一个普通段落。
  • `a`：表示一个可以跳转的链接。
  • `img`：表示一张图片。
  • `ul`、`ol`、`li`：表示无序列表、有序列表和列表项。
  • `div`：表示一个通用容器，用来组织结构。

下面是一个非常小的例子，它已经包含了标题、说明、图片和链接这几个最常见的元素。

基础结构示例
<section>
  <h1>小明</h1>
  <p>我是一名前端学习者。</p>
  <img src="avatar.jpg" alt="小明的头像">
  <a href="https://github.com/">我的 GitHub</a>
</section>

语义化标签为什么重要

初学时很容易把所有内容都塞进 `div` 里。这样虽然也能显示，但结构会越来越乱。语义化标签的意义在于：标签本身就能说明这块内容的角色。比如，`header` 表示头部，`main` 表示主体内容，`footer` 表示底部信息。

这样做的好处很多。你自己以后回头看代码时更容易理解结构，搜索引擎更容易知道页面在讲什么，辅助工具也更容易解析页面内容。

语义化页面骨架
<header>
  <h1>我的学习网站</h1>
</header>

<main>
  <section>
    <h2>前端路线</h2>
    <p>从 HTML、CSS、JavaScript 开始。</p>
  </section>
</main>

<footer>
  <p>版权信息</p>
</footer>

表单是 HTML 里很重要的一部分

登录、注册、留言、搜索、上传资料，这些功能的起点几乎都离不开表单。你可以把表单理解成“让用户把信息交给页面”的结构入口。

表单里最常见的元素包括输入框 `input`、文字提示 `label`、按钮 `button`。在后端接口配合下，表单就能成为真正可提交、可校验、可处理的数据入口。

最简单的登录表单
<form>
  <label>用户名</label>
  <input type="text" placeholder="请输入用户名">

  <label>密码</label>
  <input type="password" placeholder="请输入密码">

  <button type="submit">登录</button>
</form>

怎么练 HTML 才真正有效

最好的方式不是一直看标签列表，而是自己写一个纯结构页面。比如做一个个人介绍页，只用 HTML 搭出内容，不急着加样式。你可以包含标题、头像、技能列表、项目经历和联系表单。

当你能不看模板，自己把这些结构搭出来时，说明你已经真正理解 HTML 在做什么了。
