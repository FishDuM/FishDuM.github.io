Data Layer

没有数据层，后端系统就只是空架子

MySQL 负责长期、稳定地保存正式数据；Redis 负责快速读取高频数据。它们不是互相替代，而是分工协作。

MySQL
  • 表、字段、主键、索引。
  • 适合保存用户、订单、文章等正式业务数据。
  • 重点是“正确、稳定、可查询”。
Redis
  • 内存型缓存。
  • 适合验证码、登录状态、热点数据。
  • 重点是“快速”。
最简单的理解方式
MySQL = 正式仓库
Redis = 快速取货架

用户资料、订单记录 -> 放 MySQL
首页热门商品、登录状态 -> 放 Redis
为什么一定要分清这两者

如果你把所有东西都直接查数据库，系统会变慢；如果你把正式数据只放缓存，又容易丢失和不一致。理解分工，是后面做性能优化的前提。
