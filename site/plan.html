技术文档首页

这里是站内文档的总入口。你可以从这里进入不同方向的技术教程，例如零基础、前端、后端、Go、Python、大数据和 AI。整体结构采用传统文档形式，首页负责目录分发，具体教程页负责正文展开。

阅读入口

如果你是第一次阅读，建议先从零基础或自己当前最缺的方向开始。下面的目录会直接跳到对应技术页。

零基础与通用能力

适合完全没有开发基础，或者会抄代码但底层理解很虚的人。这里先解决共通概念和开发工具问题。

《零基础入门》：先理解编程、文件、命令行和项目结构到底是什么。

《编程基础》：变量、条件、循环、函数，是所有语言都会反复出现的底层能力。

《开发工具》：终端、编辑器、Git、排错习惯，决定你能不能稳定做项目。

前端技术文档

从网页结构、样式、交互开始，再进入组件化和框架阶段。

《HTML》：学习网页结构、语义化标签、表单和内容组织方式。

《CSS》：学习页面样式、盒模型、布局、响应式和基础视觉表达。

《JavaScript》：学习 DOM、事件、异步请求和网页交互能力。

《Vue / React》：理解组件化、状态管理和复杂前端页面的组织方式。

后端技术文档

从 Java 基础和接口开发开始，逐步进入数据库、缓存和工程能力。

《Java》：语法、类与对象、集合、异常，是后端主线的基础。

《Spring Boot》：第一个接口、参数处理、分层结构和真实业务开发入口。

《MySQL / Redis》：理解正式数据和缓存数据分别怎么存、为什么要分层。

《后端主线总览》：把 Java、Spring Boot、数据库和工程能力串成完整路线。

扩展方向文档

这些方向适合在主线稳住之后继续补，帮助你形成更完整的工程视野。

《Go》：适合补性能服务、并发思维和轻量后端能力。

《Python》：适合补自动化、数据处理和 AI 工具链能力。

《iOS / Android》：理解客户端和 Web 的差异，建立多端产品视角。

《大数据》：理解数据采集、清洗、分析和实时链路是怎么组织的。

《AI / Agent / 大模型》：从模型调用到 RAG、Agent 和工程化平台的路线。
