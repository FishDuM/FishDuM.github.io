Frameworks

框架不是魔法，它只是帮助你更稳定地做复杂页面

当页面内容开始变多，状态开始变复杂，组件开始重复，单靠原生 JavaScript 会越来越难维护。Vue 和 React 的价值，就是帮你用更清楚的方式组织这些复杂度。

Vue 3 React 组件化 后台系统
Component Thinking

先理解组件，再理解框架

按钮、输入框、对话框、表格、导航栏，其实都可以看成组件。框架真正解决的问题，不是“帮你写页面”，而是帮你把很多组件稳定地组合成一个系统。

Vue 主线
  • Vue 3、Composition API、组件通信。
  • Vue Router、Pinia、后台管理页。
  • 适合快速搭建业务系统。
React 主线
  • React、Hooks、状态管理、组件抽象。
  • 列表渲染、表单处理、路由和工程化。
  • 适合理解现代前端的组件和状态思维。
一个组件思维的简单例子
页面 = 顶部导航 + 侧边栏 + 内容区
内容区 = 搜索栏 + 表格 + 分页
表格中的每一行 = 一个可复用的数据展示单元
什么时候说明你该学框架了

当你已经能独立写出原生 HTML、CSS、JavaScript 页面，并且开始觉得“页面一复杂就很乱、逻辑不好管、组件总在重复”时，说明进入框架阶段刚刚好。

进入这一阶段前，最好已经具备
  • 能自己写基础网页结构和样式。
  • 能写简单 DOM 操作和事件处理。
  • 知道前端为什么要请求后端接口。
  • 对“组件复用”已经有直观感受。
