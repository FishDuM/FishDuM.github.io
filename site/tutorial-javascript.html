01

先用最少的语法，做最真实的事情

你前面学过的变量、数组、对象、函数、判断和循环，在 JavaScript 里都会继续出现。前端真正常用的不是炫技语法，而是这些基础能力的组合。

一个对象例子
const user = {
  name: "小明",
  age: 18,
  city: "上海"
};

console.log(user.name);
数组 适合放一组同类数据，比如多个项目、多个用户。
对象 适合描述一件具体事物，比如一个用户、一篇文章。
函数 适合把重复逻辑打包起来，比如切换主题、渲染列表。
02

DOM：JavaScript 怎么拿到页面上的元素

浏览器会把页面结构整理成一棵可操作的树，这就是 DOM。JavaScript 之所以能改标题、换图片、增删内容，就是因为它先拿到了对应的 DOM 元素。

获取元素并修改内容
const title = document.getElementById("title");
title.textContent = "新的标题";
`getElementById`

通过 `id` 找元素，直接、明确，适合单个目标。

`querySelector`

更灵活，可以用类名、标签名和层级关系查找元素。

03

事件：用户一操作，页面就响应

点击按钮、输入内容、提交表单、滚动页面，都是事件。JavaScript 常见的任务就是“监听某个事件，然后执行某段逻辑”。

点击按钮后改标题
const btn = document.getElementById("btn");
const title = document.getElementById("title");

btn.addEventListener("click", function () {
  title.textContent = "标题被改掉了";
});
第一步

先拿到按钮和标题元素。

第二步

给按钮绑定点击事件。

第三步

当点击发生时，执行修改标题的逻辑。

04

异步与接口：网页怎么和后端通信

真实网站里的数据往往不是直接写死在页面上的，而是从后端接口拿来的。JavaScript 需要负责发请求、等待结果，再把结果渲染到页面上。

最基础的 fetch 请求
async function loadUser() {
  const response = await fetch("/api/user");
  const data = await response.json();
  console.log(data);
}

loadUser();
`fetch` 向后端接口发送请求。
`await` 等待异步操作完成，再往下执行。
`response.json()` 把返回结果解析成 JavaScript 能用的对象。
05

练习项目：做一个可切换内容的学习卡片

现在你已经可以做一个最小交互作品，把 HTML、CSS、JavaScript 三层真正串起来。

建议功能
  • 页面有标题、说明文字和一个按钮。
  • 点击按钮后，标题和说明文字会切换。
  • 再加一个切换主题按钮，点击后背景和文字颜色变化。
  • 如果有余力，再做一个简单待办列表。
这一页学完后，你应该已经能做的事
  • 获取页面元素并修改内容。
  • 给按钮和输入框绑定事件。
  • 理解点击后页面为什么会发生变化。
  • 知道前端请求后端接口的大致流程。
