先学思路，再学属性

你完全没必要一开始把所有 CSS 属性背下来。真正决定你能不能做出页面的，是选择器、盒模型、Flex、Grid 和响应式这些思维方式。

01

CSS 的基本语法：选中一个元素，再给它样式

CSS 的本质非常简单：先找到你要改的元素，再写你想改的属性和对应的值。

最基础的 CSS 写法
h1 {
  color: #222;
  font-size: 32px;
}

.card {
  background: white;
  border-radius: 16px;
}
`h1` 标签选择器，表示选中所有 `h1`。
`.card` 类选择器，表示选中 class 包含 `card` 的元素。
`color`、`font-size` 样式属性，分别控制颜色和字号。
02

盒模型：页面里的每个元素都像一个盒子

理解盒模型以后，你会更容易明白为什么元素会挤在一起、为什么会留白、为什么宽度看起来不对。

`width` / `height` 控制盒子本身的宽高。
`padding` 内容和边框之间的内边距。
`margin` 元素和其他元素之间的外边距。
`border` 元素边框。
一个卡片盒子的写法
.card {
  width: 320px;
  padding: 20px;
  margin: 16px auto;
  border: 1px solid #ddd;
  border-radius: 16px;
}
新手常见误区

看到元素“太挤”就乱改宽高，其实很多时候真正该调整的是 `margin` 和 `padding`。

03

布局：让元素排成你想要的样子

布局能力是 CSS 最重要的部分之一。比如左图右文、三列卡片、一排导航、按钮靠右，本质上都是布局问题。

Flex 适合什么

适合一维排列，比如一排按钮、左右结构、水平或垂直分布。

Grid 适合什么

适合二维网格，比如卡片墙、仪表盘、复杂多列布局。

Flex 布局例子
.nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
Grid 布局例子
.project-list {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}
04

响应式：让页面在手机和电脑上都可用

一个只适合电脑看的页面，在今天是不够用的。你需要让页面根据屏幕大小自动调整布局，同时保证文字可读、按钮可点。

媒体查询例子
@media (max-width: 768px) {
  .project-list {
    grid-template-columns: 1fr;
  }
}
响应式检查重点
  • 手机上文字是不是太小。
  • 卡片会不会挤到一行放不下。
  • 按钮点击区域够不够大。
  • 深色背景下文字是否仍然清楚。
05

练习任务：把你的 HTML 骨架装修成完整主页

现在你可以把前一页写好的 HTML 骨架真正美化起来，让它像一个能展示给别人看的页面。

建议至少练这些点
  • 设置页面背景色、标题字号、正文行高。
  • 把技能列表做成标签样式。
  • 把项目经历做成卡片网格。
  • 给联系按钮做 hover 效果。
  • 让页面在手机上也不乱。
