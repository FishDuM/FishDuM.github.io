Learn By Layers

为什么前端一定要分三层来理解

网页不是“一个东西”，而是三层协作的结果。学前端最稳妥的方式，就是先搞清楚每一层各自负责什么，再把它们组合起来。

HTML
负责内容和结构
  • 标题、段落、图片、链接、列表、表单。
  • 决定页面里“有什么”。
  • 更像房子的骨架。
CSS
负责样式和布局
  • 颜色、字体、边距、边框、阴影、动画。
  • 决定页面“长什么样”。
  • 更像房子的装修。
JavaScript
负责交互和数据变化
  • 点击按钮、切换内容、提交表单、请求接口。
  • 决定页面“会不会动、会不会响应”。
  • 更像房子的电路和机关。
一个最小网页例子
<h1>我的第一个网页</h1>
<p>这是一个简单介绍。</p>
<button id="btn">点我</button>

<script>
document.getElementById("btn").addEventListener("click", function () {
    alert("按钮被点击了");
});
</script>
这一阶段最容易犯的错

把大量精力都放在“抄一个完整项目”上，却没有先把 HTML、CSS、JavaScript 各自的职责分清楚。这样会让你很难真正独立写页面。

本阶段建议你做的第一个完整作品

做一个“个人介绍主页”：有头像、简介、技能标签、项目列表、联系方式和主题切换按钮。这个小项目很适合把 HTML、CSS、JavaScript 三层串起来练一遍。
