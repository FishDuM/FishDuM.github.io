For Beginners

这一阶段到底在学什么

零基础阶段最重要的不是学“高级技术”，而是先搞清楚编程世界里最常见的几个对象分别是什么：代码是什么、文件是什么、项目是什么、命令行是什么、报错是什么。

学完后你应该能做到
  • 知道程序、网页、后端接口、数据库大概各自负责什么。
  • 能看懂最简单的代码，并知道代码为什么会执行。
  • 会创建文件、打开项目、运行代码、查看报错。
  • 能用 Git 做最基础的版本保存与同步。
推荐学习顺序
  • 先理解“编程到底是在做什么”。
  • 再学变量、判断、循环、函数这些共通概念。
  • 然后补文件、路径、终端、编辑器、Git。
  • 最后建立最基础的看报错和排错习惯。

先用一个生活比喻理解“变量”

变量就像一个贴了名字的盒子。你给盒子起名字，比如 `name`，再往里面放内容，比如“小明”。之后你要用这个内容时，不是重新写一遍“小明”，而是直接通过盒子名字把它取出来。

最小代码例子
let name = "小明";
let age = 18;

console.log(name);
console.log(age);
`let` 表示“我要创建一个变量”。
`name` 变量名，也就是盒子的名字。
`console.log(...)` 把内容打印出来，方便你看到程序当前拿到了什么。
