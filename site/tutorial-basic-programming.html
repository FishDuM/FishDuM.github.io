Core Concepts

先建立“程序是按步骤执行的”这个意识

编程本质上是在告诉计算机：先做什么，再做什么，什么情况下做哪条路，什么步骤需要重复做。只要你把这个意识建立起来，后面很多语法都会自然好理解。

01

编程到底是什么

你可以把程序理解成一份非常严格的说明书。人类说“帮我做杯奶茶”，大家大概都能猜到意思；但计算机不行，它必须知道每一步具体怎么做，顺序是什么，条件是什么。

人类表达

“把这份学生成绩整理一下。”这句话对人来说够用了，但对机器来说太模糊。

程序表达

先读取成绩列表，再判断每个成绩是否及格，再生成结果，再输出列表。程序需要的是清晰步骤。

学习重点

真正重要的不是背语法，而是学会把一个问题拆成明确、可执行的步骤。

02

变量和数据类型：程序先得有地方装数据

程序运行时，往往要先记住一些信息，比如用户名、年龄、价格、登录状态。变量就是这些信息的临时存放位置。

变量是什么

变量像一个有名字的盒子。你以后要用它里面的值，就通过盒子名字去拿。

数据类型是什么

常见有文字、数字、真假值。不同类型适合不同场景。

变量例子
let userName = "小明";
let score = 95;
let isMember = true;

console.log(userName);
console.log(score);
console.log(isMember);
`"小明"` 字符串，也就是一段文本。
`95` 数字，常用于计算、比较。
`true` 布尔值，只有真或假，常用在判断里。
新手常见错误

把变量名起得太随意，或者把本来应该是文字的内容忘了加引号。这会让代码要么难读，要么直接报错。

03

条件判断：程序怎么做选择

真实业务里几乎永远离不开“如果……就……否则……”这类逻辑。是否登录、是否有权限、是否库存充足，本质上都是判断。

最简单的 if / else
let score = 88;

if (score >= 60) {
    console.log("及格");
} else {
    console.log("不及格");
}
怎么读这段代码

先看 `if`，意思是“如果”；再看括号里的条件，意思是“分数是否大于等于 60”；条件成立就执行第一段，不成立就执行 `else` 里的另一段。

生活例子

如果下雨就带伞，否则就不带。这就是最典型的条件判断。

业务例子

如果用户已登录，就显示个人中心；否则跳转到登录页。

04

循环：程序怎么重复做事

如果一件事要做很多次，手写十遍会非常笨。循环就是把“重复执行”交给程序。

打印 1 到 5
for (let i = 1; i <= 5; i++) {
    console.log(i);
}
`let i = 1` 从 1 开始。
`i <= 5` 只要 i 还没超过 5，就继续执行。
`i++` 每执行完一次，就把 i 加 1。
遍历一个列表
let students = ["小明", "小红", "小刚"];

for (let i = 0; i < students.length; i++) {
    console.log(students[i]);
}
05

函数：把一组步骤打包起来重复使用

函数可以理解成“给一套步骤起一个名字”。你以后只要调用这个名字，程序就会把那套步骤执行一遍。

不带参数的函数
function sayHello() {
    console.log("你好");
}

sayHello();
sayHello();
带参数的函数
function sayHello(name) {
    console.log("你好，" + name);
}

sayHello("小明");
sayHello("小红");
为什么函数重要

可以复用代码，减少重复，也让代码结构更清楚。

为什么参数重要

同一套逻辑可以处理不同输入，不需要为每个人单独写一份代码。

06

练习任务：做一个学生成绩判断器

真正学会的标志不是“我看懂了例子”，而是“我可以自己写出一个相似但不完全一样的版本”。

你要完成的功能
  • 创建变量 `studentName` 和 `score`。
  • 如果分数大于等于 90，打印“优秀”。
  • 如果分数大于等于 60 但小于 90，打印“及格”。
  • 如果分数小于 60，打印“不及格”。
  • 把判断逻辑放进函数里，传入不同名字和分数重复调用。
这一页学完后，你至少应该会
  • 自己定义变量并打印出来。
  • 写出最简单的 if / else 判断。
  • 使用 for 循环处理重复任务。
  • 写一个简单函数并传入参数。
