Backend Flow

先理解一次请求到底经历了什么

浏览器向后端发请求，后端接住请求，执行业务逻辑，查询数据库，再把结果返回给前端。这就是后端最基本的工作模式。

一个最小后端流程
用户点击“查看个人信息”
-> 浏览器请求 /user/profile
-> Controller 接住请求
-> Service 处理业务规则
-> Mapper 查询数据库
-> 结果返回给 Service
-> Service 整理数据
-> Controller 返回 JSON 给前端
