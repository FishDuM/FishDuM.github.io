Spring Boot

Spring Boot 的价值，是让你把精力放在业务上

你可以先把 Spring Boot 理解成“帮你更快写后端接口的框架”。它不是代替你思考业务，而是帮你把工程结构搭好，让你更专注于接口、规则和数据处理。

第一个接口例子
@RestController
public class HelloController {
    @GetMapping("/hello")
    public String hello() {
        return "你好，Spring Boot";
    }
}
Controller
  • 接请求。
  • 收参数。
  • 返回结果。
Service
  • 写业务逻辑。
  • 组织规则。
  • 调用数据层。
Mapper
  • 操作数据库。
  • 增删改查。
  • 把表数据映射成对象。
